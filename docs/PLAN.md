## Архитектурные решения

- На первом этапе используем модульный монолит на Go.
- Границы модулей проектируем так, чтобы позднее выделить их в микросервисы.
- PostgreSQL используем как основное хранилище.
- Документ проекта храним в `JSONB`, а метаданные проекта в отдельных колонках.
- Kafka используем для событий и фоновых задач, но не для обычных CRUD-запросов.
- Для надежной публикации событий предусмотрен Transactional Outbox.
