# COMPLAN

Браузерный 3D-планировщик коммуникаций на React, TypeScript, MobX и Three.js. Сборка — Vite. Библиотека содержит 73 варианта компонентов внутренней канализации: 43 для основной линии Ø110 и 30 для Ø50. Есть поиск по названию и назначению, фильтры по диаметру и типу компонента, выбор длины трубы до добавления.

## Библиотека

- HTEM Ø50 и Ø110 с раструбом: 150, 250, 500, 750, 1000, 1500, 2000 и 3000 мм.
- HTGL Ø50 и Ø110 без раструба: 5000 мм.
- HTB Ø50 и Ø110: 15°, 30°, 45°, 67° и 87°.
- HTEA: 50/50, 50/40, 110/50, 110/75 и 110/110; для каждой комбинации — 45°, 67° и 87°.
- HTDA: 50/50/50, 110/50/50 и 110/110/110; HTED 110/110/110 — двухплоскостная. Эскизный угол боковых выходов — 87°.
- HTU, HTMM, HTAM и HTL Ø50 и Ø110; HTSM 110/110.
- HTR короткие и эксцентрические редукции, HTRI внутренние переходы: 50/40, 110/50, 110/75 и 110/90.
- HTRE, HTM, вакуумные и обратные клапаны, противопожарные манжеты, металлические и пластиковые хомуты Ø50 и Ø110.
- Ранее добавленные манжета унитаза, гильза DN150, кровельная проходка, трап и воронка разрыва струи.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и pnpm 9.15.0. Версия pnpm закреплена в `packageManager` файла `package.json`. Для установки через Corepack выполните `corepack enable` и `corepack prepare pnpm@9.15.0 --activate`.

```sh
pnpm install
pnpm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173). Опубликованная версия: https://eldarknz.github.io/complan/ . Она обновляется при каждом push в main.

```sh
pnpm run build
pnpm run preview
```

## Структура приложения

- `src/main.tsx` — точка входа React, стили и StrictMode.
- `src/App.tsx` — компоненты интерфейса: каталог, панели редактора, выбор цвета и окно спецификации.
- `src/store.ts` — MobX-хранилище фильтров, выбранных длин, цветов и спецификации. Компоненты подписаны на изменения через `observer`.
- `src/editor.ts` — контроллер Three.js: сцена, манипулятор, соединения, история и рисование трассы. Запускается из React-эффекта и освобождает обработчики, наблюдатель размеров и ресурсы сцены при размонтировании. Поля инспектора и элементы управления сценой пока обновляются контроллером через DOM.
- `src/interface.ts` — адаптер команд и обновлений между контроллером и MobX. Объекты Three.js остаются вне глубокого наблюдения; спецификация получает отдельный снимок данных.
- `src/catalog.ts`, `src/elements.ts`, `src/connections.ts`, `src/route.ts`, `src/project.ts`, `src/history.ts` — каталог, геометрия, соединения, автоподбор, формат проекта и история команд.

Исходный код приложения — TypeScript/TSX. Включена проверка неявного `any`; проверка типов выполняется перед каждой сборкой. Модульные тесты запускаются через `tsx`, браузерные — через Playwright.

## Работа с редактором

- Выберите тип и диаметр в библиотеке. У HTEM и HTGL выберите длину под карточкой, затем нажмите карточку для добавления.
- Над списком библиотеки выберите цвет новых деталей: оранжевый, белый, серый или черный. Уже стоящую трубу, отвод, тройник, крестовину, муфту, переход, заглушку, ревизию, клапан, трап или воронку можно перекрасить в панели свойств. Хомуты, противопожарные манжеты, гильза, кровельная проходка и манжета унитаза сохраняют собственный цвет. Копирование сохраняет цвет детали.
- Щёлкните по трубе для выделения. Перетаскивание фона вращает камеру, правая кнопка перемещает её, колесо меняет масштаб.
- `W` включает перемещение по мировым осям, `E` — поворот. Перетаскивайте стрелки или дуги манипулятора. Координаты и углы также можно вводить в панели справа.
- `F` показывает весь проект, `Escape` снимает выделение, `Delete` удаляет выбранный элемент.
- `Cmd/Ctrl+Z` отменяет действие, `Cmd/Ctrl+Shift+Z` повторяет его. Кнопки ↶ и ↷ находятся в верхней панели. История хранит до 10 последних команд: добавление, копирование, удаление, изменение координат, углов и длины, стыковку, разъединение и открытие проекта. Одно перетаскивание вместе с магнитной стыковкой считается одной командой. Связи и выделение восстанавливаются вместе с деталями. Новое изменение после отмены сбрасывает возможность повтора. В текстовых и числовых полях сочетания сохраняют стандартное поведение браузера для редактирования ввода. История действует до перезагрузки страницы; движения камеры в неё не входят.
- При включённой «Магнитной стыковке» новая деталь из библиотеки автоматически соединяется с выбранным свободным совместимым концом. Если подходящего конца нет, добавляется отдельно.
- Для магнитной стыковки существующих деталей нажмите `W`, двигайте деталь стрелками манипулятора и подведите свободный конец к совместимому. В пределах 90 мм от положения стыковки появляется зелёная отметка и надпись «Совместимо — отпустите мышь». При отпускании детали выравниваются и соединение закрепляется. Переключателем можно отключить магнит.
- Точки на выбранной детали доступны для щелчка: зелёный цвет — свободный конец, синий — выбранный, оранжевый — занятый.
- В разделе «Соединение» можно выбрать оба конца и присоединить новый элемент либо существующую деталь из сцены. У тройников и крестовин доступны боковые выходы. Список учитывает диаметр, тип конца и занятость. Глубина вставки эскизная: 60 мм для Ø110 и 30 мм для меньших диаметров.
- Два гладких конца (в том числе HTGL) требуют муфту; два раструба напрямую не соединяются.
- Для присоединённой детали по умолчанию включён режим «Деталь вокруг стыка» вверху панели свойств. Выберите ось соединения, нажмите `E` и тяните кольцо манипулятора: вращаются выбранная деталь и ветка с её стороны стыка, а другая сторона остаётся неподвижной. Либо задайте угол в поле «Повернуть на» и нажмите «Повернуть». Стык сохраняется; поворот поддерживает отмену и повтор. В этом режиме поля глобальных углов XYZ заблокированы, поскольку они могут нарушить совмещение концов.
- Для поворота всех связанных деталей переключите «Что вращать» на «Всю сборку». У независимой детали обычный поворот по XYZ доступен сразу. В разделе «Соединение» также можно выбрать занятый конец и использовать −15°, +15° или +90°. «Разъединить стык» освобождает оба конца без удаления деталей.
- Перемещение детали по XYZ перемещает всю связанную сборку. Изменение длины трубы переносит соседние детали, сохраняя стыки. Копирование создаёт одну независимую деталь.
- Чтобы переместить одну деталь отдельно, нажмите «Отсоединить деталь» вверху панели свойств. Кнопка освобождает все её соединения. После отсоединения детали или одного стыка первое перемещение манипулятором выполняется без магнита, чтобы соединение сразу не восстановилось. Затем магнит снова работает автоматически.
- Для ремонтной муфты выберите гладкий конец исходной трубы. Хомуты, противопожарную муфту, гильзу и кровельную проходку добавляйте из библиотеки и размещайте по XYZ вокруг трубы; канализационных портов у них нет.
- После добавления можно задать произвольную длину трубы в пределах 150–6000 мм для эскизной подрезки. Габариты фитингов и HTL фиксированы. Ось Y направлена вверх, локальная ось X трубы идёт от гладкого конца к раструбу. Координаты задают положение гладкого конца.
- «Сохранить проект» скачивает JSON версии 3 с типами, длинами, цветом, координатами, ориентациями и связями концов. «Открыть» заменяет текущую сцену содержимым файла. Старые проекты версий 1 и 2 поддерживаются и открываются без связей; детали без цвета открываются серыми. Автоматического сохранения нет. В спецификации одинаковые детали разного цвета считаются разными строками.

## Границы прототипа

Модели эскизные, без привязки к производителю: перечень вариантов взят из текстового списка, изображения каталога не предоставлены. Наружные диаметры труб — 110 и 50 мм, толщина стенки принята 3,2 и 2 мм соответственно. Длина HTEM включает раструб. Геометрия тройников и крестовин собрана из пересекающихся полых участков без булевого объединения внутренних каналов. Муфты, клапаны, трап, манжеты и проходки показаны схематически; внутренние механизмы, ход компенсации, огнестойкость и конструкция кровельного узла не рассчитываются. Монтажные размеры и типы концов специальных фитингов необходимо сверить с конкретным каталогом.

Соединения образуют разветвлённые сборки: замыкание кольца внутри одной сборки запрещено. Проверка пересечений и расчёт уклона не реализованы. Порты Ø40, Ø75 и Ø90 предусмотрены у соответствующих фитингов, но отдельные трубы этих диаметров не входят в запрошенный перечень.

## Проверки

```sh
pnpm test
pnpm run typecheck
pnpm run build
```

Тесты проверяют состав каталога, геометрию всех моделей, совмещение любых совместимых концов, магнитный поиск, поворот двумя отводами 45°, сохранность стыков при перемещении сборок, изменении длины и вращении ветки, сохранение и загрузку связей.

Для проверки редактора в Chromium:

```sh
pnpm exec playwright install chromium
pnpm run test:browser
```

Браузерные тесты автоматически запускают Vite на порту 4174 и проверяют отрисовку, выбор длины, добавление и соединение деталей, магнитную стыковку настоящим перетаскиванием манипулятора, движение сборки, разъединение, сохранение связей, переключение видов, поиск и фильтры, а также отсутствие ошибок JavaScript.
